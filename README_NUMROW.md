# QED Input — Screen Style Num Row

英語配列（QED ABC / ABC+ / CAPS）に、数字の最上段を追加した版です。

## 追加内容
- 最上段: 1 2 3 4 5 6 7 8 9 0
- その下に QWERTY
- さらにその下に ASDF / Shift+ZXCV / 下段キー

## 数字キー
- タップ: 半角数字
- 長押し: 全角数字
- 元のQED 123で使っていたフリック記号も流用

## 維持
- 英語のスクショ風下段
- 記号 / UTIL の分離
- ABC / CAPS 切替
- 数字ページ・日本語ページ・UTILITY との行き来
