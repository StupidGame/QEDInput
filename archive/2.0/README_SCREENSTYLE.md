# QED Input — Screen Style

スクリーンショットの雰囲気に寄せた英語・数字レイアウト版です。

## 英語
- 文字配列は標準QWERTY
- 下段の大きいキーは `記号` に変更
  - タップ: QED 123
  - 長押し: QED UTILITY
- 小さい右側キーは `UTIL`
- 左端は `あA`
  - タップ: QED KANA
  - 長押し: QED ABC

## 数字
- 1段目: 1 2 3 4 5 6 7 8 9 0
- 2段目: @ # % & * + - = [ ]
- 3段目: / ( ) : ; ! ? " (下フリック: _、左フリック: ') + 削除
- 下段は QED の切替系を維持

## 共通
- 空白左右フリックでカーソル移動
- 記号の多くに全角長押しあり
