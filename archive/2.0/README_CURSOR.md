# QED Input 2.0 FINAL QWERTY英数記号 + CURSOR

QED KANA の日本語カーソル移動と、横長のQWERTY型へ揃えた英語・数字・記号入力を収録しています。

## QED KANA 空白キー
- タップ → 半角スペース
- 左フリック → カーソル左
- 右フリック → カーソル右
- 左フリック長押し → 全角スペース
- 右フリック長押し → 片手/リサイズモード
- 上フリック → 既存動作を維持
- 下フリック → 既存動作を維持
- 長押し → カーソルバー

## QED KANA 右列

- 3段目 → 123
- 4段目 → 改行

## 維持
- QED KANA / ABC / ABC+ / CAPS / 123 / UTILITY
- ABC / ABC+ / CAPSはQWERTY
- 123の数字・記号もQWERTYと同じ横長キー
- ABCの文字左フリックで全角小文字、上フリックで全角大文字
- ABC+の文字左フリック、CAPSの左フリックまたは長押しで全角大文字
- CAPSの文字右フリックで全角小文字
- CAPSの複数文字入力は下フリック
