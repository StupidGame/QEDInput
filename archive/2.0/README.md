# QED Input 2.0 FINAL — QWERTY英数記号配列

英語・数字・記号は横長のQWERTY型、KANA / UTILITYは4×4です。
全角英字はQWERTYへ直接統合し、全角専用配列は使用しません。

## 起動時の配列

- 起動時に表示する日本語配列は `QED KANA 2.0` を想定しています。
- 読み込み後、azooKeyの「設定」→「キーボードの種類を設定する」→「日本語キーボードの種類」で `QED KANA 2.0` を選択してください。
- ABC / ABC+ / CAPS / 123 / UTILITYの「閉じる」操作は、QED KANAへ戻ってからキーボードを閉じます。
- 英語キーボードの種類と英語配列のキー配置は変更しません。

## QED ABC

- 文字タップ → 半角小文字
- 文字長押し → 半角大文字
- 文字左フリック → 全角小文字
- 文字上フリック → 全角大文字
- ABC+の文字タップ → 半角大文字を1文字入力してABCへ戻る
- ABC+の文字左フリック → 全角大文字を1文字入力してABCへ戻る
- CAPSの文字タップ → 半角大文字
- CAPSの文字左フリックまたは長押し → 全角大文字
- CAPSの文字右フリック → 全角小文字
- CAPSの文字キーは、中央を大きく、上下左右の補助文字を小さく表示
- CAPSの `Q`、`W`、`M` 下フリックは `QU`、`www.`、`.COM`（Wキーの表示は `ᴡᴡᴡ.`）
- ABC / ABC+ / CAPSの `Q`、`W`、`M` 下フリック → 複数文字を入力（CAPSのWキーは小文字の `www.`）

## QED 123

- 上段に `1` から `0` を横一列で配置
- 中段に使用頻度の高い記号を横長キーで配置
- 数字タップ → 半角数字
- 数字長押し → 全角数字
- 数字の各フリック記号は従来どおり維持

## 整合性修正

- KANAの拗音自動化から「にや」「によ」「みや」を除外し、「による」「みやすい」などの誤変換を防止
- KANAの単語削除区切りに半角・全角バッククォートを追加
- 123の `:` `;` `'` `"` はタップで半角、長押しで全角に統一
- 全角英字を通常の英語配列へ統合し、全角専用配列を削除
- 英語・数字・記号を横長のQWERTY型キーへ統一
- CAPSの補助文字を、左に全角大文字、右に全角小文字、下に複数文字の規則で整理
