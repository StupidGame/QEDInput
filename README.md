# QED Input 3.0

日本語・英語・数字・記号・編集操作をまとめて見直した、azooKey用Custard配列です。
名前は **QED KANA / QED ABC / QED ABC+ / QED CAPS / QED 123 / QED UTILITY** を引き継いでいます。

「片手でも両手でも、文字を探す・打ち間違いを直す・画面を切り替える負担を減らす」ことを目指しています。
最速・世界一という実測結果はありません。長押しの速度やキーの幅は、手の大きさと端末によって調整してください。

## 導入

1. [00_QED_Input_KANA_DEFAULT_3.0.json](00_QED_Input_KANA_DEFAULT_3.0.json)を端末に保存します。
2. azooKeyの「カスタムタブの管理」のファイル読み込みから開き、保存します。
3. 日本語キーボードに **QED KANA 3.0**、必要なら英語キーボードに **QED ABC 3.0** を選びます。

一括ファイルを読み込めない場合は、次の6ファイルをすべて個別に読み込んでください。

| 用途 | ファイル |
| --- | --- |
| 日本語 | [QED_KANA_3.0.json](QED_KANA_3.0.json) |
| 小文字英語 | [QED_ABC_3.0.json](QED_ABC_3.0.json) |
| 一度だけ大文字 | [QED_ABC_Plus_3.0.json](QED_ABC_Plus_3.0.json) |
| 大文字固定 | [QED_CAPS_3.0.json](QED_CAPS_3.0.json) |
| 数字・記号 | [QED_123_3.0.json](QED_123_3.0.json) |
| 定型文・追加記号 | [QED_UTILITY_3.0.json](QED_UTILITY_3.0.json) |

一括版と個別版の内容は同じです。両方を読み込む必要はありません。
読み込み順だけでは起動時のキーボードを指定できないため、日本語キーボードの設定も行ってください。
表示名・内部IDは3.0専用なので、端末上の2.0とは共存できます。
元のJSONと説明書は、内容を変えずに[archive/2.0](archive/2.0/)へ移しています。

## 使い方の共通ルール

KANA・123・UTILITYは **5列×4段** です。文字を中央3列、編集と切り替えを両側へまとめています。
英語は数字列付きQWERTYです。全6タブで、空白と削除の動作を揃えています。

| キー・操作 | 動作 |
| --- | --- |
| 空白をタップ | 半角スペース |
| 空白の左右フリック | カーソルを1文字移動 |
| 空白の左右フリックを保持 | 同じ方向へ繰り返し移動 |
| 空白を長押し | カーソルバー |
| 空白を上フリック | 貼り付け |
| 空白の上フリックを保持 | クリップボード履歴 |
| 空白を下フリック | 全角スペース |
| ⌫をタップ／長押し | 1文字削除／1文字ずつ連続削除 |
| ⌫を上フリック／保持 | カーソル直後の1文字を削除／連続削除 |
| ⌫を左フリック | 空白・句読点・記号の手前まで削除 |
| ⌫を下フリック | KANAへ戻ってキーボードを閉じる |
| 操作をタップ | UTILITYへ移動 |
| 操作を長押し／上フリック | 幅・片手モードの調整 |
| 操作を下フリック | タブバーを表示・非表示 |

貼り付け・履歴にはazooKeyのフルアクセス許可が必要です。
「区切」削除は日本語の形態素解析ではなく、スペースや記号を境にします。
すぐ手前が区切り文字の場合は止まります。その区切りを消すときは⌫をタップしてください。

独立した **←／→** キーもタップで1文字、長押しで連続移動できます。
上フリックで改行まで文頭方向、下フリックで改行まで文末方向へ移動します。
ここでいう行は改行文字による区切りで、画面上の自動折り返しではありません。

**ABC・あA・123の切り替えキー** は、タップで表示先、左フリックでKANA、上でCAPS、右でABC、下で123、長押しでUTILITYです。
UTILITYの左下「戻る」はKANAへ戻ります。

## QED KANA 3.0

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| ABC | う | か | し | ⌫ |
| ← | に | い | た | 空白 |
| → | の | ん | と | 123 |
| 操作 | お | 小゛゜ | は | 改行 |

おぐら配列の頻出文字と連続入力の考え方を参考にしています。
「い」「ん」を中央へ置き、五十音の行に限定せず、よく使う文字をタップや隣接方向へ割り当てました。
通常の五十音フリックとは方向が違うため、最初は次の表を見ながら練習してください。

| タップ | ← | ↑ | → | ↓ |
| :---: | :---: | :---: | :---: | :---: |
| う | む | わ | ち | せ |
| か | よ | つ | く | ら |
| し | ゆ | や | じ | っ |
| に | ね | そ | な | も |
| い | き | り | ま | る |
| た | て | す | え | め |
| の | ろ | ど | さ | み |
| ん | だ | が | で | を |
| と | こ | あ | 、 | れ |
| お | へ | ほ | け | ぬ |
| 小゛゜ | 「 | ー | 」 | 半濁点 |
| は | ふ | ひ | ？ | 。 |

- 清音の長押しで濁音を入力できます。例：か→が、せ→ぜ、へ→べ、う→ゔ。
- あ・い・え・お・や・ゆ・よ・わの長押しで小文字を入力できます。フリック先を保持した場合も同じです。
- 「ぅ」は「う→小゛゜」で入力します。「う」の長押しは「ゔ」です。
- 「っ」は「し」の下フリックです。そのまま保持すると「つ」になります。
- 「ぬ」は「お」の下フリックです。「ん」の長押しでも入力できます。
- 「小゛゜」のタップはazooKey標準の濁点・半濁点・小文字切り替えです。下フリックは半濁点専用なので、「は→小゛゜↓」で「ぱ」を選べます。
- 「小゛゜」の長押しは「・」、上フリックの保持は「〜」、左右フリックの保持は「（」「）」です。
- 「？」の保持で「！」、「、」「。」の保持でもう一方を入力できます。

**通常入力では、拗音化・略語展開・括弧や長音の自動置換をしません。**
「しよう」「ひよう」「による」「みやすい」は、入力した文字のままになります。
「きょう」は「き→よのフリックを保持→う」または「き→よ→小゛゜→う」で入力できます。
同じ括弧や「ー」を繰り返しても別の記号には変わりません。閉じ括弧は明示的に入力します。

## QED ABC / ABC+ / CAPS 3.0

QWERTYの並びと数字列を引き継ぎ、全角入力と大文字の扱いを揃えています。

```text
1 2 3 4 5 6 7 8 9 0
q w e r t y u i o p
 a s d f g h j k l
⇧ z x c v b n m ⌫
あA  .  空白  123  操作  改行
```

| タブ | タップ | 左フリック | 上フリック | 右フリック | 長押し |
| --- | --- | --- | --- | --- | --- |
| ABC | 半角小文字 | 全角小文字 | 全角大文字 | — | 半角大文字 |
| ABC+ | 半角大文字 | 全角大文字 | — | — | 全角大文字 |
| CAPS | 半角大文字 | 全角大文字 | — | 全角小文字 | 全角大文字 |

ABC+は文字を入力するとABCへ戻ります。文字のフリックや長押しにも適用します。
ABCの⇧をタップするとABC+、長押しするとCAPSです。ABC+／CAPSの⇧／⇪タップでABCへ戻ります。

- **Bも他の文字と同じ規則**で「ｂ」「Ｂ」を入力できます。#はBの下フリック、保持で＃です。
- Qの下フリックはqu／QU、Wはどのタブでもwww.、Mは.com／.COMです。保持で全角になります。
- ⇧／⇪の左・上・右・下フリックは、順にバッククォート・単引用符・二重引用符・アンダースコアです。
- 「.」の左・上・右・下フリックは「,」「?」「!」「:」です。長押しは「…」、下フリック保持は「;」です。
- 数字列はタップで半角、長押しで全角です。下記123と同じ記号フリックも利用できます。

## QED 123 3.0

電話番号・金額・日時の入力で小さい数字を狙わずに済むよう、数字をテンキーへ組み直しています。
英語タブには横一列の数字もあるので、英文中の数字は切り替えなしでも入力できます。

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| ABC | 1 | 2 | 3 | ⌫ |
| ← | 4 | 5 | 6 | 空白 |
| → | 7 | 8 | 9 | + |
| 操作 | . | 0 | - | 改行 |

| タップ | ← | ↑ | → | ↓ |
| :---: | :---: | :---: | :---: | :---: |
| 1 | @ | & | # | * |
| 2 | ( | [ | ) | ] |
| 3 | { | < | } | > |
| 4 | + | - | × | ÷ |
| 5 | = | ≠ | ≦ | ≧ |
| 6 | ＼の半角 | &#124; | / | _ |
| 7 | : | ; | ' | " |
| 8 | ¥ | $ | % | ° |
| 9 | ^ | ~ | バッククォート | … |
| 0 | 00 | + | - | % |
| . | , | : | ; | / |
| - | _ | ? | ! | = |
| + | - | * | / | = |

数字の長押しで全角数字を入力できます。数字キー内の記号にも長押し候補があります。
例：5の右フリックは≦、保持で<=。2の上フリックは[、保持で［です。
7の引用符は「'→＇」「"→＂」の規則で、長押ししても曲がった引用符にはなりません。
右列の「+」はASCII演算子用、4キーの「×」「÷」は文章中の数式用です。
かなへ戻るには、ABCキーの左フリック、または「操作」の左フリックを使えます。

## QED UTILITY 3.0

| | | | | |
| :---: | :---: | :---: | :---: | :---: |
| ABC | 挨拶 | 返事 | 丁寧 | ⌫ |
| ← | 「 | 」 | 記号 | 空白 |
| → | URL | 開発 | MD | 123 |
| 戻る | 数式 | 単位 | 矢印 | 改行 |

入力後もUTILITYに留まるため、複数の記号を続けて入力できます。左下「戻る」でKANAへ戻ります。

| キー | タップ | ← | ↑ | → | ↓ | 長押し |
| --- | --- | --- | --- | --- | --- | --- |
| 挨拶 | ありがとうございます | ありがとう | よろしくお願いします | お願いします | お疲れさまです | すみません |
| 返事 | 了解です | はい | 大丈夫です | わかりました | なるほど | 承知しました |
| 丁寧 | 失礼します | 失礼しました | お世話になっております | ご確認お願いします | 申し訳ありません | よろしくお願いいたします |
| 「 | 「 | （ | 【 | 『 | ［ | 〈 |
| 」 | 」 | ） | 】 | 』 | ］ | 〉 |
| 記号 | … | ・ | 〜 | ※ | ✓ | —— |
| URL | https:// | http:// | www. | .com | .jp | :// |
| 開発 | / | ＼の半角 | &#124; | & | _ | => |
| MD | # と空白 | # | バッククォート | > と空白 | * と空白 | ** |
| 数式 | = | ≠ | ≦ | ≧ | ± | ≈ |
| 単位 | 円 | % | ℃ | kg | km | cm |
| 矢印 | → | ← | ↑ | ⇒ | ↓ | ⇔ |

返事の左右上下フリックを保持すると、左＝なので・上＝つまり・右＝たとえば・下＝ですがを入力できます。
MDの左フリック保持は＃、上フリック保持はバッククォート3つと改行です。
Markdownでも閉じ側の記号は自動挿入せず、カーソルを勝手に戻しません。

## 持ち方と慣らし方

- **右手・左手の片手入力**：操作キーの長押しから幅と位置を調整してください。かなの中央3列と、空白・削除に無理なく届く幅を優先します。
- **両手入力**：中央の「い」「ん」を目印に左右で分担してください。同じ配列なので、片手から持ち替えても文字を覚え直す必要はありません。
- **長文**：←／→と空白の左右フリックで修正します。カーソル操作の途中で全角空白やサイズ変更へ変わることはありません。
- **英数混在**：英文中は数字列、連続した数値は123、追加記号はUTILITYを使い分けてください。

5列化により、同じキーボード幅ならKANAの各キーは2.0の4列より狭くなります。
中央の到達距離と編集キーを増やす利点との交換です。押し間違える場合は、幅を狭めすぎずに調整してください。
長押しは指を別キーへ動かす回数を減らしますが、待ち時間は必要です。速さだけでなく、誤入力と疲れにくさも見てください。

練習には「こんにちは」「きょうのよてい」「しようをかくにん」「によるちがい」「みやすいはいれつ」、
「Mail123@example.com」「2026/09/18」「-1234.50」などを使えます。
同じ文章で入力時間・訂正回数・届きにくいキーを比較すると、次の調整点を判断しやすくなります。

## 検証と再生成

生成済みJSONだけで利用できます。開発用ツールはPython標準ライブラリだけで実行できます。

```powershell
python tools/build_layouts.py
python -m unittest discover -s tests -v
```

一括版と個別版の一致、キーの重なり・範囲、文字の入力経路、全角B、ABC+の復帰、タブ間移動、
普通のかな語句を変形しないこと、数字・記号の入力、カーソルと削除の共通動作を検証しています。
テストはJSONとアクションのモデルによる確認で、iPhoneでの読み込み・描画・変換エンジン・タッチ判定の実機確認は未実施です。
「小゛゜」の変換そのものはazooKey標準機能を呼び出すため、その動作も実機確認の対象です。

## 参考にした設計

- [おぐら配列／作者のリポジトリ](https://github.com/JEEBIS27/azookey_ogura)：頻出かなを直接打つ配置と、次の文字へつながるフリック方向。
- [大西拓磨さんの長押し濁音入力](https://note.com/illlilllililill/n/n67de54ef099e)：清音の長押しで濁音を入力する操作。
- [azooKeyの標準日本語フリック](https://github.com/azooKey/azooKey/blob/main/AzooKeyCore/Sources/KeyboardViews/Custard/FlickJapaneseCustard.swift)：中央3列と左右の操作列を持つ5列×4段。
- [Custardの仕様](https://github.com/azooKey/CustardKit/blob/main/json/howToMake.md)、[現行のCustard型定義](https://github.com/azooKey/azooKey/blob/main/AzooKeyCore/Sources/CustardKit/CustardKit.swift)：JSON・フリック・長押し・タブ移動。

QED Input 3.0はこれらの考え方を既存のQED Inputと組み合わせて再設計したものです。
おぐら配列そのものとの互換性や、入力速度の優位性を保証するものではありません。
アプリ用の版番号は3.0ですが、ファイル形式を示す`custard_version`は対応形式の`1.2`です。
