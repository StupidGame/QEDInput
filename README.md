# QED Input 3.0

**元のQED Input 2.0の配置と操作を引き継ぎ、細かな補修に絞った3.0です。**
KANA・UTILITYは4×4、ABC・ABC+・CAPSは数字列付きQWERTY、123は数字が上段に横一列で並ぶ構成です。
全6タブで既存キーの位置・大きさ・タップ・フリック入力を元に戻しています。
使い方と変更点は、このREADMEに統一しています。

## 読み込み

一括ファイルに対応しない場合は、下記6ファイルを個別に読み込んでください。

前の3.0と表示名・内部IDは同じです。すでに導入している場合は、この内容で更新してください。

元の2.0のJSONは[archive/2.0](archive/2.0/)に保存しています。

## 二重引用符をすぐに入力

**次の切り替えキーを上フリックすると、半角の `"` を1文字入力できます。**
タブを切り替えず、そのまま入力を続けられます。保持すると全角の `＂` です。
キーにも `↑"` の目印を表示しています。

| タブ | 上フリックするキー |
| --- | --- |
| KANA | 左下のABC、または右列3段目の123 |
| ABC・ABC+・CAPS | 最下段、空白の右の「記号」 |
| 123 | 最下段、空白の右のABC |
| UTILITY | 最下段のABC |

元の引用符入力も同じ場所で使えます。引用符の自動ペア入力は行いません。
ABC+でも引用符を打っただけではタブを戻さず、続く英字を大文字で入力できます。

## 2.0からの細かな変更

| 対象 | 変更内容 |
| --- | --- |
| KANA「よ」 | 補助表示にフリック方向の矢印を追加しました。入力は同じです。 |
| KANA「小゛゜」 | 表示から抜けていた下フリックの「ぬ」を補足しました。入力は同じです。 |
| ABCのb | 空いていた右フリックへ「ｂ」を追加しました。左の#、上のＢ、長押しのBはそのままです。 |
| ABC+のB | 空いていた右フリックへ「Ｂ→ABCへ戻る」を追加しました。左の#はそのままです。 |
| CAPSのB | 左フリックの表示を実際の入力である#へ修正しました。全角Ｂは従来どおり長押しです。 |
| 123の引用符 | 一部の長押しで出ていた曲がった引用符を、全角＇／＂へ統一しました。 |
| UTILITYの括弧 | フリック先の未使用だった長押しで、対応する閉じ括弧を入力できるようにしました。 |
| 英数切り替えキー | 上記の空いていた上フリックへ二重引用符を追加しました。 |

UTILITYの括弧キーは、左フリック保持＝）、上＝】、右＝』、下＝］です。
通常フリックの（・【・『・［、タップの「、キー中央の長押しの〈は元どおりです。
中央の補助表示も、タップと長押しに合わせています。

## 元の配置と操作

KANAのタップ位置です。濁音の長押し、拗音の自動化、略語入力も2.0と同じです。

| | | | |
| :---: | :---: | :---: | :---: |
| い | か | し | ⌫ |
| と | の | は | 空白 |
| ま | よ | る | 123 |
| ABC | ん | 小゛゜ | 改行 |

「や・ゆ・よ」は対象の文字に続くと自動で小文字になります。
小文字化せず入力するときは、その「や・ゆ・よ」を長押しします。
「にや」「によ」「みや」を自動小文字化しない既存の例外も保持しています。
「小゛゜」による「あり→ありがとう」などの略語展開と、括弧・長音の繰り返し置換も元どおりです。

英語は元のQWERTYと数字列を保持しています。ABC+の大文字1文字入力後の復帰、CAPS固定、Q・W・Mの短縮入力も2.0と同じです。
ABCではタップで半角小文字、長押しで半角大文字、左フリックで全角小文字、上フリックで全角大文字です。
ABC+・CAPSの左フリックは全角大文字、CAPSの右フリックは全角小文字です。Bだけは上記の#ショートカットを優先します。
記号キー・UTILキー・あAキー・空白・削除の位置と既存操作も引き継いでいます。

123は次の並びです。数字の長押しによる全角化や、数字キー内の記号フリックも従来どおりです。

```text
1 2 3 4 5 6 7 8 9 0
@ # % & * + - = [ ]
/ ( ) : ; ! ? " ⌫
あA  .,! ?  空白  ABC  UTIL  改行
```

UTILITYは元の16キーを同じ場所に置いています。接続詞、定型文、Markdownのテンプレート入力も引き継いでいます。

| | | | |
| :---: | :---: | :---: | :---: |
| 挨拶 | 返事 | 丁寧 | 接続 |
| 括弧 | 記号 | 矢印 | MD |
| URL | 開発 | 数式 | 単位 |
| あいう | ABC | 123 | 改行 |

KANAの空白は、左右フリックでカーソル移動、左フリック保持で全角空白、右フリック保持で片手・サイズ調整です。
上フリックの貼り付け、下フリックの履歴、中央長押しのカーソルバーも元どおりです。
貼り付け・クリップボード履歴にはフルアクセス許可が必要です。

## 検証・再生成

```powershell
python tools/build_layouts.py
python -m unittest discover -s tests -v
```

生成時は保存済み2.0を読み込み、上記の変更だけを適用します。
テストでは、全タブの配置・キーサイズ・元のタップ／フリック動作が一致すること、
記載したキー以外に差分がないこと、元のかな自動化、追加した入力、タブ間移動、一括版と個別版の一致を確認します。
iPhone上の読み込み・描画・押し心地・変換エンジンは未検証です。
表示上のバージョンは3.0、Custardファイル形式のバージョンは従来の1.2です。


## MFM

Misskey向けの専用タブ `QED MFM 3.0` を同梱しています。

- Utilityの「MFM」をタップするとMFMタブへ移動します。
- `$[x2 ]`、`$[ruby ]`、色、枠、フォント、回転、位置、各種アニメーションなどを直接入力できます。
- テンプレート系キーは入力後にカーソルを閉じ記号の内側へ戻すため、そのまま本文を入力できます。
- アニメーションキーの長押しでは `speed=5s` 版を利用できます。
- 下段から「あいう」「ABC」「123」「Utility」へ戻れます。

MFMの構文はMisskey公式ドキュメントの現行仕様に合わせています。
