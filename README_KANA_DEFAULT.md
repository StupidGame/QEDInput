# QED Input — KANA DEFAULT

この版では QED KANA 2.0 を一括インポートデータの先頭にしています。

推奨:
- `00_QED_Input_KANA_DEFAULT.json` を1ファイルだけ読み込む
- 収録順は KANA → ABC → ABC+ → CAPS → 123 → UTILITY

また、ABC / ABC+ / CAPS / UTILITY の「閉じる」操作は
QED KANAへ戻してからキーボードを閉じるようにしています。

注意:
Custard形式そのものには「起動時のデフォルトタブ」を強制指定する項目がありません。
azooKey側で日本語キーボードの種類が別のものに設定されている場合は、
一度だけ QED KANA 2.0 を日本語キーボードとして選択してください。
